# ContextHub 展示页面

这是 ContextHub 项目的官方展示页面，灵感来源于 [SpecStory](https://specstory.com/) 的现代化设计。

## 🎨 设计特色

- **现代化设计**: 深色主题，渐变色彩，玻璃态效果
- **响应式布局**: 适配桌面、平板、手机等不同设备
- **动画效果**: 平滑滚动、渐入动画、终端模拟
- **交互体验**: 按钮悬停效果、导航滚动监听

## 📱 页面结构

### 1. 导航栏
- 固定顶部，毛玻璃效果
- 品牌Logo和名称
- 导航菜单（功能、解决方案、文档、GitHub）
- CTA按钮

### 2. Hero区域
- 主标题："上下文是新的源代码"
- 子标题和产品介绍
- 行动按钮（立即体验、查看文档）
- 终端演示窗口

### 3. 功能展示
三个主要功能卡片：
- **多模型支持**: Kimi、OpenAI、Claude
- **标准化上下文**: .ct格式转换
- **开发者友好**: 多种使用方式

### 4. 价值主张
面向三类用户的价值说明：
- **个人开发者**: 提升开发效率
- **团队协作**: 共享上下文知识
- **未来发展**: 构建知识资产

### 5. 产品演示
- 代码示例展示
- 标签页切换功能
- 语法高亮显示

### 6. 社会证明
展示支持的AI模型和技术：
- Moonshot AI、OpenAI、Anthropic
- 开源社区、Python、GitHub

### 7. 行动号召
- 最终转化区域
- 主要和次要按钮
- 功能特性图标

### 8. 页脚
- 品牌信息和标语
- 产品链接、解决方案、资源
- 联系方式和法律信息

## 🚀 使用方法

### 本地预览
1. 将文件放在本地服务器中
2. 打开 `index.html`
3. 确保所有资源文件路径正确

### 部署
- 可部署到任何静态网站托管服务
- 支持 GitHub Pages、Netlify、Vercel 等
- 确保相对路径正确

## 🎯 关键特性

### CSS变量系统
使用CSS自定义属性管理：
- 颜色主题
- 间距规范
- 阴影和圆角
- 响应式断点

### JavaScript交互
- 平滑滚动导航
- 终端打字动画
- 卡片渐入效果
- 按钮交互反馈

### 响应式设计
三个主要断点：
- 桌面: > 1024px
- 平板: 768px - 1024px  
- 手机: < 768px

## 🛠️ 技术栈

- **HTML5**: 语义化标签
- **CSS3**: 现代特性（Grid、Flexbox、CSS变量）
- **JavaScript**: 原生ES6+
- **字体**: Inter字体（Google Fonts）
- **图标**: 内联SVG

## 📝 自定义指南

### 修改颜色主题
在 `style.css` 的 `:root` 选择器中修改CSS变量：

```css
:root {
    --primary-gradient: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
    --bg-primary: #0a0a0a;
    --text-primary: #ffffff;
    /* ... 其他变量 */
}
```

### 更新内容
直接修改 `index.html` 中的文本内容：
- 标题和描述
- 功能说明
- 联系信息

### 添加动画
在 `script.js` 中添加新的动画函数：
- 使用 `IntersectionObserver` 监听滚动
- 添加CSS过渡和变换
- 控制动画时机和效果
